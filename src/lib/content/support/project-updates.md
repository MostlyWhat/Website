## Project Update Requests

Need to make changes to your existing project? Here's how to request updates.

## Types of Updates

### Content Updates
- Text changes
- Image replacements
- Adding new pages
- Blog post publications

**Turnaround:** 1-2 business days

### Design Updates
- Color scheme changes
- Layout modifications
- New component designs
- Branding updates

**Turnaround:** 3-5 business days

### Feature Updates
- New functionality
- Integration additions
- Performance improvements
- Security updates

**Turnaround:** Varies by scope

## How to Request

### 1. Gather Your Requirements
Before submitting, prepare:
- Clear description of changes needed
- Reference images or examples
- Affected pages or sections
- Priority level

### 2. Submit Your Request
Use our [ticket form](/support#ticket-form) with:
- Subject: "[Project Name] Update Request"
- Priority: Based on urgency
- Message: Detailed requirements

### 3. Review Our Quote
For larger updates, we'll provide:
- Time estimate
- Cost estimate (if applicable)
- Implementation plan

### 4. Approval & Scheduling
Once approved, we'll:
- Schedule the work
- Provide expected completion date
- Keep you updated on progress

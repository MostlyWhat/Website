## Reporting Bugs Effectively

When you encounter an issue, providing detailed information helps us resolve it quickly.

## Required Information

Please include the following in your bug report:

### 1. Description
A clear, concise description of what went wrong.

**Bad:** "The site is broken"
**Good:** "The contact form shows an error after submitting, but the form data is not received"

### 2. Steps to Reproduce
Numbered steps to recreate the issue:

1. Go to [specific page URL]
2. Click on [specific element]
3. Enter [specific data]
4. Click submit
5. See error

### 3. Expected Behavior
What you expected to happen.

### 4. Actual Behavior
What actually happened instead.

### 5. Environment Details
- **Browser:** Chrome 119, Firefox 120, Safari 17, etc.
- **Device:** Desktop, Mobile, Tablet
- **Operating System:** Windows 11, macOS 14, iOS 17, etc.
- **Screen Size:** 1920x1080, 375x812, etc.

### 6. Screenshots or Videos
Visual evidence is incredibly helpful. Use tools like:
- Windows: Snipping Tool or Win+Shift+S
- macOS: Cmd+Shift+4
- Browser: Built-in screenshot tools

### 7. Console Errors
If you're technical, open the browser console (F12) and check for any red error messages.

## Submitting Your Report

You can submit bug reports through:

1. **Support Ticket** - Use our [ticket form](/support#ticket-form)
2. **Email** - Send to support@mostlywhat.com
3. **Project Management** - If you have access to our project board

## Priority Levels

- **Critical** - Site is completely down or unusable
- **High** - Major feature is broken, affecting users
- **Normal** - Bug affecting functionality but with workaround
- **Low** - Minor visual issue or enhancement

## What Happens Next

1. We acknowledge your report within 24 hours
2. We investigate and reproduce the issue
3. We provide an estimated fix timeline
4. We notify you when the fix is deployed

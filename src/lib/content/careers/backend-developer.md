## About the Role

We're looking for a Backend Developer to help build our serverless infrastructure. You'll work with modern edge computing technologies to create fast, scalable APIs and services.

## What You'll Do

- Design and implement RESTful APIs and GraphQL endpoints
- Build serverless functions on Cloudflare Workers
- Work with databases like D1, Turso, or PostgreSQL
- Implement authentication and authorization systems
- Optimize for performance at the edge

## Requirements

- 3+ years of backend development experience
- Strong proficiency in TypeScript/JavaScript
- Experience with serverless architectures
- Knowledge of database design and optimization
- Understanding of API design principles
- Experience with testing and CI/CD

## Nice to Have

- Experience with Cloudflare Workers or similar edge platforms
- Knowledge of Rust or Go
- Experience with real-time systems (WebSockets)
- Background in DevOps or infrastructure

## Contract Details

- 3-6 month contract with potential for extension
- Full-time commitment (40 hours/week)
- Competitive hourly rate
- Fully remote position

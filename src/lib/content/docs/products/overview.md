# Products Overview

Welcome to the MostlyWhat Systems product documentation. Here you'll find comprehensive guides for building, deploying, and maintaining web applications using our recommended stack and best practices.

## What We Build

We specialize in modern, performant web applications using cutting-edge technologies:

- **SvelteKit Applications** — Full-stack web applications with server-side rendering
- **Static Sites** — Lightning-fast static websites for content and marketing
- **Dashboards** — Data visualization and admin interfaces
- **API Services** — RESTful and GraphQL backend services

## Technology Stack

Our recommended technology stack includes:

| Layer | Technology |
|-------|------------|
| Frontend | SvelteKit, Svelte 5, TypeScript |
| Styling | Tailwind CSS v4, Custom Design System |
| Backend | SvelteKit API Routes, Cloudflare Workers |
| Database | Cloudflare D1, Drizzle ORM |
| Deployment | Cloudflare Pages, Vercel |

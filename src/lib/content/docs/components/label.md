# Label

Renders an accessible label associated with controls.

## Installation

```ts
import { Label } from '$lib/components/ui/label';
```

## Default

A standard label.

```svelte live
<Label>Email Address</Label>
```

## Props

| Prop | Type | Default |
|------|------|---------|
| `for` | `string` | `""` |

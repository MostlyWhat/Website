A comprehensive guide to our design language, grid system, components, and patterns. Everything you need to build consistent, beautiful interfaces.

## Getting Started

Start by exploring our foundation elements:

- **Grid System** — 12-column responsive grid with 1px gap borders
- **Colors** — Cobalt blue primary with yellow and red accents
- **Typography** — Four distinct typefaces for different purposes
- **Components** — Comprehensive UI component library

## Design Philosophy

Our design system embraces an industrial aesthetic with sharp edges, high contrast, and purposeful motion. Every element is intentional and aligned to the grid.

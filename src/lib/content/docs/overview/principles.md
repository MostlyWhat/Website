# Design Principles

Our design system is built on four core principles that guide every decision we make.

## 01 — Industrial Precision

No rounded corners. Sharp edges. Grid-based layouts. Every element is intentional and aligned.

The industrial aesthetic creates a sense of precision and professionalism. All components snap to the grid, borders are sharp, and spacing is consistent.

## 02 — High Contrast

Dark backgrounds with vibrant cobalt blue accents create visual impact and hierarchy.

Our dark-first approach reduces eye strain while making content and interactive elements pop. The cobalt blue primary color draws attention to key actions.

## 03 — Typography First

Clear hierarchy through type scale and weight. Four distinct typefaces for different purposes.

| Typeface | Usage |
|----------|-------|
| Tourney | Headlines & display text |
| Hubot Sans | Body text & paragraphs |
| Chakra Petch | UI elements & buttons |
| JetBrains Mono | Code & technical text |

## 04 — Motion with Purpose

Scroll-based animations that enhance rather than distract. Subtle, meaningful transitions.

Animations are triggered by scroll position using Intersection Observer. They fade, slide, or scale elements into view as the user navigates the page.
